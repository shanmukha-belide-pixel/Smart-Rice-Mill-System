📡 API Endpoints
POST /api/otp/send Generate & send OTP via email, SMS, or both. Body: { type, email?, phone? }
POST /api/otp/verify Verify the OTP (one-time use). Body: { identifier, otp }
GET /api/otp/status?identifier=… Check if an OTP is pending, time remaining, and attempts used.
POST /api/otp/clear Manually invalidate an OTP. Body: { identifier }
